Entity profile + navigation model

Two mechanisms, working together, using real Machines content. Outer tab strip (top) is which entity's profile you have open — closable, click a machine to add one. Inner side sub-nav (inside a profile) is which section of that one entity you're looking at. Click workshop-desktop in the list, then try "Start new chat" inside its profile — that's the "open somewhere else" question, made concrete with three real destinations to compare.

What each destination actually costs
Same tab (replace)

Cheapest to build — it's what the app already does. But you lose the profile you were reading; "back" is the only way home, and back loses scroll position and any unsaved sub-nav state.

New in-app tab

The tab strip above is this. Real new work: a tab manager, state per tab, deciding what happens on reload. Best for anything you'll work in for more than a minute — a real chat, a second machine's profile.

Centre modal

Cheapest of the "don't lose my place" options — a Dialog primitive, already installed. Right for a quick capture (one message, one field). Wrong for a real chat thread — a modal that scrolls internally fights the reading-column rule in §8.1.
