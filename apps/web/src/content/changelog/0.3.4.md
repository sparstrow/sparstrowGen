title: An update-and-restart no longer risks leaving the app broken
---

**Fixed**

- **Installing an update and restarting no longer risks a broken app
  afterward.** The update quit this app's own server without stopping the
  background process it runs on your computer's port 8080. If that process
  was still healthy when the update fired, it could survive as an orphan
  holding the port — leaving the freshly-updated app with no way to start its
  own copy. It is now stopped along with everything else before an update
  installs.
- **A logging problem could no longer silently take the whole app down.**
  Opening the log file this app writes to could fail in a way nothing was
  listening for, which — rarely, but observed on a real machine right after
  an update — meant the app kept running with no record of what it was doing,
  right when that record mattered most. A failure here now just turns
  logging off for that session instead of risking the app itself.

**Still not working**

- Sending a message to an agent gets no reply. An agent created in the app does
  not yet exist on any computer, so there is nothing for it to run. That is next.
