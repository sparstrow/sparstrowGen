title: The desktop app is a real app
---

**New**

- **Sparstrowgen is now a desktop application in its own right.** It used to run
  a whole web server inside itself just to draw a window. That is gone — the app
  is a native window that talks to a Sparstrow server, the same way the website
  does. It opens faster, installs smaller, and can finally do things the website
  cannot.
- **Sign in through your browser.** Press one button and Sparstrowgen opens the
  browser you are already signed in to. There is no password field in the app,
  and there will not be one.
- **Your machines, in the app.** The computer you are running on registers
  itself and appears with its platform, hostname and live status. Nothing to
  pair, no code to type.
- **A Settings screen**, with the two things that had no home: updates, and
  whether the local agent service starts and stops with the app.
- **Update notifications.** When a new version is published, Sparstrowgen tells
  you — in the app and, if the window is closed, through your operating system.
  It never downloads or installs on its own; both are your click, and an install
  waits for any agent run in progress to finish first.

**Improved**

- One release channel instead of two. Merging to `main` with a new version
  number publishes the release automatically — there is no longer a draft
  sitting on GitHub waiting for someone to remember to press Publish.

**Fixed**

- The app quit instantly, with no window and no error, on any build run outside
  an installer. It had been doing this for as long as the desktop app has
  existed.
- Deleting a chat session silently did nothing.

**Before you install**

- **Uninstall "Sparstrowgen Staging" first** if you have it. There is only one
  channel now, and the two apps compete for the same local port — whichever
  starts second ends up with no working service. Staging will not receive
  another release.

**Known limitations in this release**

- Sending a message to an agent and getting a reply is not finished. The message
  reaches your machine and the agent starts, but replies do not yet stream back
  into the window.
