**Fixed**

- **Your computer now appears after you sign in.** In 0.3.0 you could install the
  app, sign in successfully, and still be told "No machines yet" — forever.
  Connecting a computer was a step that existed everywhere except in the app
  itself: the code that does it was complete and correct, and nothing ever ran
  it. Sparstrowgen now claims this computer by itself, when it starts and again
  the moment you sign in. There is no button to press, because there is nothing
  left for you to confirm.
- **The model list was out of date, and quietly wrong.** It offered three Gemini
  3.5 Flash options that no longer exist, and hid nine that do — every 3.6, 3.7
  and 3.8 Flash tier. The list is now read from the provider itself wherever the
  provider can be asked, and where a shortcut like `opus` or `sonnet` exists,
  that is now the first thing offered: those always mean the newest model, so
  they cannot go out of date.

**About this release**

This is the release that proves the update mechanism, which is why it exists at
all. "An update is available" is a comparison between the version you have
installed and the version that has been published — so it cannot be tested with
one release, only with a second one. If you are reading this because
Sparstrowgen told you 0.3.1 was ready, then the thing it was built to
demonstrate has just demonstrated itself.

**Still not working, same as 0.3.0**

- Sending a message to an agent does not get a reply. The message reaches your
  machine and the agent starts, but an agent you create in the app does not yet
  exist on any computer, so it has nothing to run. That is the next thing being
  built.
