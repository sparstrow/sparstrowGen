**New**

- The desktop app now ships as two separate installs: **Sparstrowgen**, which
  tracks `main` and your production data, and **Sparstrowgen Staging**, which
  tracks the `staging` branch and updates itself automatically on every push —
  no manual release step. They install side by side without conflicting.
- This page. Every release — stable or staging — gets an entry here, and the
  in-app update notification links straight to what changed.

**Improved**

- The app now reports its real version to the desktop shell consistently
  (previously a stale value could appear in one place).
