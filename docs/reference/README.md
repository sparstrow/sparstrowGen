# Reference

Historical and point-in-time material — nothing here is a live plan. If you're looking for
what's actually being worked on, see [`docs/workflows/`](../workflows/) (process) or
[`docs/planned/`](../planned/) (open, unbuilt plans). For what's shipped, `.design-src/APP.md`
is the single source of truth.

```
audits/           point-in-time reports (design, security, architecture) — findings from
                   that date, not the current state
shipped-plans/     plans that were followed and the feature actually shipped — kept for
                   historical detail; the merged record lives in .design-src/APP.md
superseded/        plans/sketches that were replaced or abandoned before completion — kept
                   for early-thinking history only
```

Every file here carries a status blockquote at the top so a reader landing on it cold knows
immediately what they're looking at.
