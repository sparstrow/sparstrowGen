Focus is forced on the second field so the ring is comparable without tabbing. Click into the first to see the real behaviour — the ring is inset (outline-offset:-1px) so it does not push adjacent rows in a dense form.
The invalid field is the one worth studying. Red border, plus aria-invalid, plus a message that says what to do — and aria-describedby tying them together, which is what makes a screen reader read the message when focus lands. A red border on its own passes a glance and fails a user.
Every field above has a real Label. The placeholder in the first is example content, not the label — it vanishes the moment someone types, which is exactly when they most need to know what the field was.
Disabled says why. A greyed field with no adjacent reason reads as broken rather than intentional.
