The card sits one lightness step above the page. That step plus the 1px line is the entire elevation vocabulary.
Rule
A shadow appears only when an element genuinely floats above the page — dropdown, popover, command palette. If a card, panel, or table has a drop shadow, that is a defect, not a style preference. No glow, no glassmorphism blur.
