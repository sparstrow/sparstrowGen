This is the fifth colour role, not a leftover. Only the classes highlight.js actually emits are styled; anything else falls through to --foreground. The values sit one step calmer than a typical editor theme because code here appears inside a monitoring surface, not an editor.

Named rule — Syntax Is Not Themed. A user's surface or accent choice does not reach these six. Tinting them with the surface costs about a third of the perceptual separation between them, and mapping them onto the status and brand roles costs about half — and makes a green string literal read as online.
