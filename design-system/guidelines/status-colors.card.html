Rule
Chroma is held near-constant across the four so no status shouts louder than another by accident; only hue varies. Every other colour in the system is chroma 0 — a consequence of the retired doctrine’s accent budget, not a rule anyone still defends. The owner has asked for status to read more strongly; see DECISIONS.md DD-002.
Pairing
Each status is a --x / --x-foreground pair. Both flip between themes: in light the surface is pale and the text saturated; in dark that inverts. Never pair a status background with --foreground — contrast fails in one theme or the other.
