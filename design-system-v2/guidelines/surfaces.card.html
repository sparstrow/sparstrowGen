Chroma is 0 on every neutral above. The ramp is pure greyscale in both modes — no warmth, no cast. Dark mode is a .dark class, not a media query, so :root is light and the app overrides to dark.
Light mode used to have no surface ramp. background, card, and popover were all oklch(1 0 0) — the same pure white — so a light-mode surface separated only by its borders. Fixed 2026-08-19. Light now runs 0.985 / 1.0 / 0.955 and dark runs 0.145 / 0.195 / 0.245, both derived rather than transcribed, so every mode has three real steps.
Four surface characters, all real. DESIGN.md §2.2 defines Paper (hue 85, chroma 0.010), Slate (250, 0.011), Soft (280, 0.007) and Mono (0, 0), each with a light and dark expression. All four ship as root classes — add surface-slate to <html> and every neutral above re-derives. The app defaults to Paper.

Surface is orthogonal to brand: changing one does not move the other. And surface hue is not a tuning lever — at chroma 0.010 a hue shift is below the threshold of visibility, so if an accent needs more separation, move the brand hue instead (§2.3).
These values are generated. They come from packages/shared/src/theme/tokens.ts via the marked block in globals.css. This card mirrors that block. G-19 — the gap that said §2 described a system the app did not have — closed 2026-08-19.
