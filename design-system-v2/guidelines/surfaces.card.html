Chroma is 0 on every neutral above. The ramp is pure greyscale in both modes — no warmth, no cast. Dark mode is a .dark class, not a media query, so :root is light and the app overrides to dark.
Light mode has no surface ramp at all. background, card, and popover are all oklch(1 0 0) — the same pure white — so the right pane above separates only by its borders. Dark mode does have three real steps (0.145 / 0.205 / 0.269). DESIGN.md §2.2 specifies a differentiated light ramp (--background at 0.985 against --card at 1.0); the app does not implement it. This is not a rendering artefact of the card — it is what ships.
Specified but not built. DESIGN.md §2.2 defines four surface characters — Paper (hue 85, chroma 0.010), Slate (250, 0.011), Soft (280, 0.007), Mono (0, 0) — each with a light and dark expression derived from five root variables. None of that exists here. Every value above is a hand-maintained literal with no relationship the code enforces between its light and dark form, which is why Paper and Mono cannot be shown side by side: today the app only has Mono, and it has it by accident rather than by choice.
