Tuned denser than shadcn’s defaults — 13px body rather than 14px — because this is a monitoring surface, read in long sittings and scanned rather than read.
Every size above is a literal in this card, not a token. DESIGN.md §3 says so itself: the scale is “a new decision, not mirrored from the app”. The only typography token that exists is --font-sans. There is no --font-mono either — the mono row above uses the raw stack §3 names.

In the codebase, sizes come from Tailwind steps (text-xs, text-sm) or arbitrary literals: the 2026-08-19 slop audit counted 97 uses of text-[10px] / text-[11px], several of them below the 11px floor this scale defines. Sweeping them is deliberately not in doc/tasks/D1/ — there is nothing to sweep them onto until the scale ships as CSS. Adding the tokens here first would invent them, which is doc/KnownGaps.md G-18.
