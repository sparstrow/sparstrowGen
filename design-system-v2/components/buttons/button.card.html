Hover is live — put the cursor on any variant above. Focus-visible is forced on the third button in the States row so the ring is comparable without tabbing; in the real component it appears only on keyboard focus, never on mouse click.
Shadow is per-variant, not global. default, destructive, outline, and secondary carry a small shadow; ghost and link deliberately do not — they are meant to sit inside dense rows without stacking depth. There are no shadow tokens, so this is a Tailwind shadow-sm at each call site.
