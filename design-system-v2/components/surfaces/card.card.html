Same information, twice. The left card separates rows with a 1px divider and nothing else. The right one wraps each row in its own bordered surface, which adds three more edges, two more radii, and a second elevation level that means nothing — and makes every row look independently clickable when none of them is.
nested-cards is a certain-tier rule in ai-design-slop: depth used as a substitute for hierarchy. Spacing, weight, and dividers do this job without adding a surface. If rows need to be distinguishable, change the type or the spacing — not the container.
Parts are Card › CardHeader › CardTitle · CardDescription › CardContent › CardFooter. Cards sit on --background and are --card themselves — which in light mode are currently the same white, so the border is doing all the separating. See the Surfaces guideline.
