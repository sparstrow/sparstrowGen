Shaped like the row it replaces
The right frame is the whole component in one idea. Same three-line primitive, sized per element — avatar, name, subtitle, status chip — so the layout does not move when the real rows arrive. The left frame loads for the same duration and tells the user nothing about what is coming.
Skeleton, not a spinner, wherever the shape is knowable. A spinner says something is happening; a skeleton says what. Both frames animate with the real spg-pulse keyframe from globals.css — 1s ease-in-out, infinite.
Nothing here respects prefers-reduced-motion, because nothing in the app does — verified 2026-08-19. On a page of skeletons that is a lot of motion for a user who asked for none.
